# Gatherly

## Project Name
Gatherly

## Project Statement
Gatherly is a neighborhood exchange platform that helps people share useful items, skills, and local opportunities with the people who live nearby. The project is designed to make everyday community support easier to discover by bringing lending, giving, and requesting into one friendly digital space.

The application will focus on trust, clarity, and low-friction participation. Members will be able to create a profile, publish an item or offer, search for local resources, and communicate with one another through the platform. Over the semester, the project will grow from this presentation layer into a full-stack application with authentication, persistent data, and interactive community workflows.

## Target Audience
The primary users are local residents, students, families, and community-minded people who want to borrow, give away, request, or offer useful things and skills in their area.

## Core Features
- Create an account and manage a personal profile.
- Post items, skills, or requests with photos and descriptions.
- Search and filter nearby listings by category and availability.
- Save listings and message other members about an exchange.
- Track active, reserved, and completed exchanges.
