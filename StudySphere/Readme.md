# StudySphere

## Project Name
StudySphere

## Project Statement
StudySphere is a campus-focused study planning platform that helps college students turn busy academic schedules into practical daily plans. The application will give students one organized place to record courses, assignments, study sessions, and deadlines. Its purpose is to make academic work easier to see, prioritize, and complete before important due dates arrive.

The platform will support students who balance classes, work, and personal commitments by presenting their workload in a clear visual schedule. Instead of relying on scattered notes, calendars, and reminders, users will be able to plan focused study time, track progress toward assignments, and receive useful deadline reminders. StudySphere aims to encourage steady habits and reduce the stress caused by last-minute work.

## Target Audience
The primary users are college students, especially students managing several courses, assignments, work shifts, and extracurricular responsibilities.

## Core Features
- User authentication so students can create private accounts and securely save their schedules.
- Profile creation so users can personalize their academic information, courses, and study goals.
- Assignment and deadline tracking with due dates, priorities, and completion status.
- Study-session scheduling that lets users create, edit, and organize focused time blocks.
- Progress tracking that displays completed work and upcoming priorities.
